# Alternative Alphabet Game (Web Edition)

A **gamified version of the original Alternative Alphabet card game**, designed to promote **mental health awareness among young adults**.

> **Note:** This is the **Web Edition**. A separate **[Java Edition](https://github.com/JishnuSetia/AlternativeAlphabet-JavaEdition)** of the game also exists.

Play the game online here: [Alternative Alphabet Game](https://alternative-alphabet-jishnu-setia.surge.sh/)

---

## Features

* Fun, interactive card game experience
* Encourages **mental health reflection** and discussion
* Browser-based — no downloads required

---

## How to Play

1. Open the game link in your browser.
2. Follow the instructions on each card.
3. Complete rounds to explore alternative alphabet prompts and improve mental awareness.
